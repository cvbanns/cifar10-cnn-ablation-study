CIFAR-10 controlled study

Data and evaluation
- Use the official CIFAR-10 training data to create a stratified 45,000/5,000
  train/validation split with 500 validation images per class and split seed 2026.
- Use matched training seeds 17, 29, and 43. Use the same data, batch size of 64,
  Adam optimizer, and initial learning rate of 0.001 in every arm.
- Use each run's first best-validation-accuracy checkpoint.
- Use validation accuracy for all ablation comparisons. Evaluate the reproduced
  baseline and selected configuration on the official test set after selection.
- Report mean and sample standard deviation over seeds. The minimum target is
  78% mean test accuracy for the selected configuration.

Comparisons
1. For each 30-epoch run of the original configuration, compare the best
   validation accuracy in its first two epochs with its best across 30 epochs.
   Report the independently trained two-epoch baseline as a separate reference.
2. Compare the combined candidate with four variants. In each variant, restore
   one original factor: architecture, augmentation, dropout, or LR schedule.
3. Compare the selected model and reproduced baseline on the official test set.
   Include per-seed accuracy and confusion matrices.

The original notebook and report record the historical experiments.
